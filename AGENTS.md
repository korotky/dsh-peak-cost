# Инструкции для агентов

Плагин DeepSeek Harness: пилюля с периодом тарифа и стоимостью сессии. Этот файл — карта
проекта для агента, который открывает репозиторий впервые.

## Команды

```sh
npm test            # 58 тестов на чистых функциях: календарь, цены, свёртка, web-сборы, леджер
npm run typecheck   # tsc по JSDoc (checkJs), без компиляции
npm run format      # prettier
npm run build       # dist/*.tgz с проверкой состава пакета
```

## Инварианты, которые нельзя ломать без ADR

- **Цена по моменту запроса.** Каждый запрос ценится на свой момент (таблица цен + фаза),
  а не по текущему времени. См. ADR 0001.
- **Никакой сети и ключей.** Плагин не обращается к API DeepSeek и не читает баланс.
  Единственная сеть — необязательное обновление календаря праздников по URL из настроек.
- **Тарифы и календарь — данные плагина.** В API хоста их нет; обновляются релизом. См. ADR 0003.
- **Леджер без своего состояния.** «Сегодня/неделя» выводятся из логов сессий, файла нет.
  См. ADR 0002.
- **Настройки — в settings-документе хоста**, через `settings.update('peak-cost')`. Файла
  настроек и localStorage нет. См. ADR 0004.
- **Неизвестная модель не подменяется** ценой Flash: ноль и флаг.

## Осторожно

- `client.js` — браузерная половина: грузится через `window.__ModuleLoader__.load`, React
  берётся из модульной таблицы хоста. Сборки нет, поэтому проверять синтаксис и загрузку
  нужно вручную (`node --check`, см. DEV.md).
- Слоты `plugins.row.config` и `plugins.bundle.config` — keyed по id записи и имени пакета.
  Переименование пакета или записи ломает форму настроек.
- При установке ссылкой горячая замена не работает — это не баг кода, см. ADR 0005.
- Тесты покрывают только чистые функции. Интерфейс проверяется глазами через CDP (DEV.md).
