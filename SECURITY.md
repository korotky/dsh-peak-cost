# Security

## Что делает плагин

- Читает durable-логи сессий Harness через `sessionQuery` и считает по ним стоимость.
- Отдаёт браузеру снимок состояния по маршруту `/api/dsh-peak-cost/state`.
- Пишет настройки через `settings.update` (запись профиля).
- Не имеет API-ключей, не обращается к сети, кроме необязательного обновления календаря
  праздников по URL, который вы сами указали в `~/.dsh/peak-cost-holidays.json`.

## Границы доверия

- Маршрут наследует проверку доверия хоста (`connection.requestRejection`): без валидной
  cookie браузера запрос отклоняется, чужой `Host`/`Origin` — тоже.
- Тело POST ограничено 4 КиБ; значения настроек проверяются по типу и допустимому набору,
  всё остальное отбрасывается.
- Плагин не исполняет внешний код и не пишет файлы вне `~/.dsh`.

## Сообщить об уязвимости

Откройте private security advisory в GitHub или напишите автору репозитория. Пожалуйста,
не публикуйте детали до исправления.
