# 01: Каркас пакета и пилюля-заглушка

**What to build:** Плагин устанавливается в профиль `web` и после перезагрузки страницы виден в списке плагинов как установленный бандл — со своим названием, описанием и иконкой. В строке статистики под композером появляется нейтральная пилюля с текстом-заглушкой. Ничего не считает, ничего не запрашивает.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Пакет ставится в профиль по абсолютному пути без запросов на approve build-скриптов
- [ ] Бандл виден в Plugins с локализованными названием и описанием и собственной иконкой
- [ ] Пилюля появляется в строке статистики правее официальных, в пустой сессии тоже
- [ ] Включение и отключение бандла не оставляет ошибок в консоли
- [ ] Удаление плагина не оставляет файлов состояния
