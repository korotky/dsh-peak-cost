# 03: Таблица цен и оценка сессии

**What to build:** Пилюля показывает оценку стоимости текущей сессии, посчитанную по официальным ставкам: четыре бакета токенов, цена выбирается на момент каждого запроса, cache-write тарифицируется по ставке cache-miss. Неизвестная модель не подменяется Flash-ценой, а помечается.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Тест шва цен: сумма по четырём бакетам на известном примере совпадает с ручным расчётом по официальной странице
- [ ] Cache-write считается по ставке cache-miss
- [ ] До и после снижения цен 10.09.2026 применяется своя версия таблицы по дате события
- [ ] `deepseek-v4-pro` считается по собственной таблице, legacy-алиасы Flash — по Flash
- [ ] Неизвестная модель даёт ноль и признак «цена неизвестна», а не правдоподобную цифру
- [ ] Обе валюты считаются независимо, без пересчёта по курсу
