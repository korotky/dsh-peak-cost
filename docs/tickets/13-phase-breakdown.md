# 13: Разбивка стоимости по периодам

**What to build:** В детализации видно, сколько запросов и сколько денег пришлось на пик, а сколько — на off-peak. Это позволяет увидеть, что часть сессии шла по двойному тарифу, не открывая счёт DeepSeek.

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] Стоимость делится на пиковую и off-peak части, и их сумма равна общему итогу
- [ ] В поповере две строки: «Пик» и «Вне пика» с числом запросов и суммой
- [ ] Строки появляются только для тех фаз, в которых были запросы
- [ ] Сессия, целиком прошедшая в одной фазе, показывает одну строку и не создаёт пустую
- [ ] Обе валюты в разбивке считаются независимо
