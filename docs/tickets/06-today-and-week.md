# 06: Сегодня и неделя

**What to build:** В поповере появляются суммы за сегодня и за текущую неделю, собранные из durable-логов сессий, с кэшем в памяти на минуту. Собственного файла состояния плагин не заводит.

**Blocked by:** 04, 05

**Status:** ready-for-agent

- [ ] Суммы за сегодня и неделю совпадают с суммой по сессиям, начатым в этих периодах
- [ ] Сессия, начатая до установки плагина, учитывается целиком
- [ ] Повторное открытие поповера в течение минуты не пересчитывает логи заново
- [ ] После закрытия и переоткрытия Harness цифры восстанавливаются из логов, а не из файла
- [ ] Измерено время сборки недели; если заметно медленно — зафиксировано в отчёте тикета
