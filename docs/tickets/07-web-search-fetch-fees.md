# 07: Web search и fetch

**What to build:** В детализации видна стоимость web-поиска и fetch — они биллятся за успешный запрос, а не за токены. Учитываются только успешные вызовы, и только начиная с даты официального начала биллинга.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Успешные вызовы считаются, неуспешные и пустые — нет
- [ ] Вызовы до даты начала биллинга показываются как бесплатные
- [ ] Строка появляется только когда вызовы были
- [ ] Мультизапросный поиск считается по числу запросов
- [ ] Стоимость складывается с токенной суммой в общем итоге
