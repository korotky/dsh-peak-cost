# 02: Фаза пика и обратный отсчёт

**What to build:** Пилюля показывает текущий период («Пик» или «Off-peak»), цветную точку перед словом и время до переключения. Значение верно для будней, выходных, праздников КНР и перенесённых рабочих суббот и не зависит от часового пояса процесса.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Тесты календаря на границах всех четырёх UTC-окон проходят
- [ ] Выходной и праздник дают off-peak весь день; перенесённая рабочая суббота тоже off-peak (официально выходные — off-peak целиком)
- [ ] Следующее переключение верно через границу суток и через праздничный блок
- [ ] В браузере цвет меняется при смене периода, отсчёт точен в пределах минуты
- [ ] Пересчёт происходит при возврате фокуса и смене видимости вкладки
