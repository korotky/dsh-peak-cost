# 05: Сабагенты и форки

**What to build:** Расход сабагент-сессий входит в общую сумму и одновременно показывается отдельной строкой с числом сессий. Форки в сумму не попадают, потому что их токены уже посчитаны в родительской сессии.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Тест шва агрегации: сабагент-сессия включается в сумму и видна отдельной строкой
- [ ] Вложенный сабагент (сабагент сабагента) учитывается один раз, без двойного счёта
- [ ] Унаследованный префикс событий не считается дважды
- [ ] Форк исключается из суммы
- [ ] Если сервис трассировки сессий недоступен, пилюля продолжает работать и сообщает об ограничении
