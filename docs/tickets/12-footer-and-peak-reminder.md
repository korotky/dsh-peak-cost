# 12: Футер сайдбара и напоминание о пике

**What to build:** Два необязательных элемента, по умолчанию выключенных: строка периода в футере левого сайдбара и напоминание при входе в пик. Напоминание не повторяется чаще заданного интервала и молчит в off-peak.

**Blocked by:** 02, 08

**Status:** ready-for-agent

- [ ] Строка в футере сайдбара появляется только при включённой настройке
- [ ] Напоминание срабатывает при входе в пик и не срабатывает при входе в off-peak
- [ ] Интервал напоминаний настраивается и соблюдается
- [ ] Напоминание не перекрывает ввод и не появляется во время off-peak
- [ ] Оба элемента выключаются без перезапуска Harness
