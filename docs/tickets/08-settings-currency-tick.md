# 08: Настройки, валюта, частота обновления

**What to build:** Секция настроек плагина: выбор валюты для пилюли, частота пересчёта периода, переключатели дополнительных элементов (появятся в тикете 12). Изменения применяются без перезапуска Harness.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] Секция видна в настройках плагинов и сохраняет значения между перезапусками
- [ ] Переключение валюты сразу меняет цифру в пилюле, поповер продолжает показывать обе
- [ ] Частота пересчёта настраивается в разумных пределах и применяется без рестарта
- [ ] Некорректные значения не ломают плагин, а откатываются к умолчаниям
- [ ] Настройки описываются схемой, а не ручным парсингом
