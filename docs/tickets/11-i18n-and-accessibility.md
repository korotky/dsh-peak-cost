# 11: Локализация и доступность

**What to build:** Весь интерфейс плагина читается на русском и английском по языку Harness, без захардкоженных строк. Пилюля доступна с клавиатуры, период слышен скринридером, поповер управляется без мыши.

**Blocked by:** 04, 08

**Status:** ready-for-agent

- [ ] Смена языка Harness меняет все строки плагина, включая метаданные бандла
- [ ] Ни одной пользовательской строки вне словарей
- [ ] Пилюля и поповер полностью управляются с клавиатуры, фокус видим
- [ ] Период и сумма озвучиваются через `aria-label`
- [ ] Числа, суммы и время форматируются по активной локали
