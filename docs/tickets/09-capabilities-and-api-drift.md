# 09: Капабилити и диагностика дрейфа API

**What to build:** Плагин проверяет доступные сервисы, проекции и поля при старте и сообщает результат. Если чего-то нет — пилюля сужает отображение, но не исчезает; в поповере видно, что именно не найдено, версия хоста и ожидаемый диапазон, есть кнопка повторной проверки.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] Список проверок выполняется при старте и по кнопке «проверить снова»
- [ ] Отсутствие проекции токенов оставляет пилюлю с периодом и явной диагностикой
- [ ] Отсутствие сервиса агрегации отключает только суммы, а не весь контрол
- [ ] В диагностике видны версия хоста и ожидаемый диапазон совместимости
- [ ] Ни один сценарий отказа не приводит к падению плагина или пустому месту в строке статистики
