# 04: Поповер детализации

**What to build:** Клик по пилюле открывает поповер: период и время до переключения, стоимость сессии, разбивка по четырём бакетам, версия применённой таблицы цен с датой, обе валюты. Закрывается по Escape и клику вне, открывается и в пустой сессии.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Поповер открывается кликом и с клавиатуры, закрывается Escape и кликом вне
- [ ] Порядок блоков: период, деньги, разбивка, диагностика (последняя только при проблемах)
- [ ] В разбивке видны все четыре бакета и ставка каждого
- [ ] Видна версия таблицы цен и дата, с которой она действует
- [ ] В пустой сессии открывается и показывает период и нули
- [ ] Поповер не перекрывает композер и не ломает ввод
