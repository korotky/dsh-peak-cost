# Цены и правила пиков — данные плагина, а не хоста

В API DeepSeek Harness 0.2.1-rc.5 нет ни цен, ни тарифных окон, ни признака скидки: хост отдаёт только токены и кэш-бакеты. Поэтому таблицы цен и правила пиков объявляются внутри плагина с датами вступления в силу, обновляются релизом плагина, а календарь праздников дополнительно может подтягиваться из нашего же JSON. Отвергнуто: тянуть цены или календарь из сторонних сервисов и API в рантайме — это внешний источник правды, который ломается молча. Следствие, которое надо помнить: при изменении цен у DeepSeek цифры врут, пока не выйдет релиз плагина, поэтому применённая версия таблицы показывается в детализации.
