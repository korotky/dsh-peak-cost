# Оценка по моменту запроса, а не по текущему времени

Сумма считается по `event.time` каждого запроса, с выбором версии таблицы цен и фазы пика на этот момент. Отвергнуто: считать всю сессию по текущему периоду и текущей таблице (проще, но цифра скачет при переходе границы, а турн, пересекающий 12:00 или 18:00, получает одну неверную ставку — так делает WHALE, берущий `Date.now()` при обработке сообщения). Необратимо: это форма расчёта, а не деталь отображения; исправление позже означает другую историю цифр.
