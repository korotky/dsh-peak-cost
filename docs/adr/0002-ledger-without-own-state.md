# Леджер без собственного файла состояния

«Сегодня» и «неделя» собираются из durable-логов сессий через `sessionQuery` с кэшем в памяти (60 с), а не из своего JSON на диске. Отвергнуто: файл-накопитель (так делают WHALE и peak-reminder) — он даёт второй источник правды, расходится с логами после откатов и ручных правок и переживает переустановку плагина, показывая цифры неизвестного происхождения. Риск принятого решения: агрегация за неделю может оказаться медленной; тогда добавим кэш на диск, но лишь после измерения, и он останется производным от логов.
