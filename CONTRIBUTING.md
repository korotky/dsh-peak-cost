# Contributing

Спасибо, что заглянули. Плагин маленький, поэтому правила простые.

## Что приветствуется

- Исправления расчётов: правил пиков, таблиц цен, учёта бакетов и web-вызовов.
- Диагностика расхождений с платформой DeepSeek — с логами или расчётом.
- Новые тесты на границы (праздники КНР, переходы периодов, неизвестные модели).

## Что не принимается

- Сетевые запросы без явной настройки и без оффлайн-фолбэка.
- Телеметрия и аналитика: плагин не должен знать, кто вы.
- Маркетинговые формулировки в описаниях: они проверяются против кода.
- Зависимости ради одной функции.

## Процесс

1. `git clone`, `npm ci`.
2. Изменение + тест, который падал бы без него (`npm test`).
3. Проверки перед PR: `npm run typecheck && npm run format:check && npm test && npm run build`.
4. PR с описанием: что меняется и почему; для правок расчёта — ссылка на первоисточник
   (страница цен DeepSeek, постановление о праздниках).

## Границы домена

Термины живут в [CONTEXT.md](CONTEXT.md): пик, off-peak, бакет, фаза турна, оценка против
списания. Решения с последствиями записаны в [docs/adr](docs/adr) — если меняете поведение
вопреки ADR, обновите ADR в том же PR.

## Стиль

Форматирование — Prettier (`npm run format`), типы — JSDoc + `tsc` (`npm run typecheck`).
Комментарии и документация — по-русски; публичные описания пакета — по-английски.
